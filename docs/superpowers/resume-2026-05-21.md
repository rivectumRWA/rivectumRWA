## Style refresher (sticky)

- Card primitive: `featured`, `compact`, `span={1|2|3}`, `className` props. TR + BL `+` glyphs auto.
- Microlabel: `<span className="microlabel">label</span>` — 11px UPPERCASE 0.08em tracking
- Color tokens: `text-text` (#050505), `text-text-muted` (#5F666A), `text-text-subtle` (#8A8A82), `text-success` (#2F8C4A), `text-danger` (#B23A2F), `bg-accent` (#B6F42C lime — sparingly)
- Tabular nums: `font-mono` + `tabular` class
- Badge variants: enabled/blocked/ready/fresh/empty/info/neutral/low/medium/high
- Section labels: `<SectionLabel title="x">` with hairline divider, no F-NN numbering
- Page headers: F-001 (overview), F-002 (vault), F-003 (activity)

## Decision log

- ECDSA secp256k1 untuk intent signing (bukan Ed25519) — cheap on-chain ecrecover. Sudah documented di spec.
- Single EOA owner (no real multisig) untuk hackathon scope
- SQLite local untuk agent decision log (tidak Postgres)
- Demo mode via `NEXT_PUBLIC_DEMO=1` untuk pitch screenshots tanpa deployed contract
- 60/40 max BPS per asset, 6000/4000 split sebagai default allocation
- 5-minute rebalance interval default
